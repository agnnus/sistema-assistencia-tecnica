# sistema-assistencia-tecnica
Sistema para gerenciamento de clientes, aparelhos e ordens de serviço de uma assistência técnica.
Sistema de Assistência Técnica

Projeto desenvolvido para praticar programação e construir, passo a passo, um sistema de gerenciamento para uma assistência técnica.

🎯 Objetivo

Criar um sistema capaz de organizar informações de clientes, aparelhos e futuramente ordens de serviço.

🚧 Desenvolvimento atual

Atualmente, o sistema possui um cadastro interativo de clientes pelo terminal, coletando:

Nome
Telefone
E-mail
Aparelho
Marca
Modelo
Problema relatado

Os dados são armazenados em um objeto JavaScript.
